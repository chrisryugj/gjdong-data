# gjdong-data

광진구 생활 대시보드(gjdong.vercel.app)가 읽는 공개 자료.

- `data` 브랜치: 서울·광진 명소 혼잡 히트맵(`heatmap.json`), 3시간마다 갱신
- `data-jeju` 브랜치: 제주 명소 생활인구 스냅샷(`jeju.json`)·히트맵(`jeju-heatmap.json`), 매시 갱신

자료 원천: 서울 열린데이터광장 실시간 도시데이터, 제주 공공 생활인구 등 공공 개방 데이터. 등급 산출 방법은 https://gjdong.vercel.app/crowd/methodology
